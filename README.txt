  Run                                                                                                                                                                                                                                                                            
                                                            
  1. Click the Radii toolbar icon, or Vector menu → Radii → Radii: geodesic circles from CSV…                                                                                                                                                                                    
  2. Browse to a CSV (try example.csv from the plugin folder).
  3. Set the accuracy tolerance — the label next to it updates live ("≈ 71 segments at r=1 km, 703 at r=100 km" at 1 m tolerance).                                                                                                                                               
  4. Leave Reload automatically ticked, click OK.                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                                 
  Two layers appear in the Layers panel: Radii — geodesic circles and Radii — centers. Right-click → Zoom to Layer.                                                                                                                                                              
                                                                                                                                                                                                                                                                                 
  CSV format                                                                                                                                                                                                                                                                     
                                                            
  lat,lon,height,radius,color                                                                                                                                                                                                                                                    
  48.2082,16.3738,171,1500,ff0000                           
  "48 12 50.12","16 22 25.68",180,5000,00aa00                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                 
  - lat/lon: decimal (48.2082) or DMS (48 12 50.12, 48°12'50.12"N, 48:12:50.12)                                                                                                                                                                                                  
  - radius: meters                                                                                                                                                                                                                                                               
  - color: optional, rrggbb or #rrggbb; falls back to the dialog's default                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                                 
  Live editing
                                                                                                                                                                                                                                                                                 
  Keep the dialog closed — just edit the CSV in any editor and save. The file watcher picks it up within ~250 ms and redraws. Parse errors show in QGIS's message bar; the old layer stays until the CSV is valid again.                                                         
   
  Re-configure                                                                                                                                                                                                                                                                   
                                                            
  Click the toolbar icon again to change tolerance, default color, or swap CSVs — the existing layers are reused rather than duplicated.
